# 已确认的引物 Excel 交付格式

适用于新交付及旧表改版。修改已有表时先读取用户最新保存版本；保持现有数据、评价、标黄、配对身份及证据。仅改版式或命名时不重新设计、不改 PP5 数值或验证结论。样例格式已确认后，后续同格式续表直接沿用；改变布局时先提供一对真实引物的样例。

## 每对两行与命名

- 主表每对占两行，先 F 后 R。两条序列均为订购方向 5′→3′。
- 全部候选统一命名，包含原批次、补筛、备选及用户指定候选：`BP{原始输入序号}_CDS_F ({原候选编号})` / `BP{原始输入序号}_CDS_R ({原候选编号})`。例如 `BP6_CDS_F (R06-1)`、`BP6_CDS_R (R06-1)`；旧候选为 `BP6_CDS_F (06-1)`。序号取输入顺序，不取表格行号；括号内编号保留不变。
- F/R 各自的名称、方向、序列、Tm、GC、长度、False Priming、Hairpin ΔG 和 Dimer ΔG分别占独立行，不合并。
- 每对共用的基因、产物、配对指标、验证结论、评价和备注等字段纵向合并两行；值或公式仅放合并区左上角，下行留空。不同配对之间不合并。
- `CDS` 是用户要求的名称组成部分，不证明完整 CDS 覆盖；partial、覆盖率及克隆范围限制仍照实报告。

## 主表列顺序（已确认的38列）

| 列 | 字段 | 每对共用/合并 |
|---|---|---|
| A–B | 原始序号、基因 | 是 |
| C–H | 引物名称（原候选编号）、方向、5′→3′序列、PP5 Tm(°C)、GC(%)、长度(nt) | 否 |
| I–N | 产物(bp)、用户评价、评价备注、特异性结论、序列ID、候选级别 | 是 |
| O–Q | False Priming、Hairpin ΔG、Dimer ΔG | 否 |
| R–V | Cross Dimer ΔG、配对温差、PP5 3′结构数、结构提示、CDS覆盖率 | 是 |
| W–AC | 产物起点/终点、CDS起点/终点、CDS区间长度、CDS重叠bp、PP5评分 | 是 |
| AD–AL | Primer-BLAST原始状态、基因层面状态、其他基因潜在产物、最近长度差、同基因额外转录本、报告链接、问题说明、完整模板SHA256、PP5截图对应编号 | 是 |

- J 列为用户评价，K 列为评价备注；同步更新方法页、说明及任何旧列位置引用。评价可用“待评价/用户选用/可用/不可用/需调整”，不能把用户选用等同于软件或实验验证通过。
- PP5 ΔG 单位 kcal/mol；无结构提示写 None，未知另标。False Priming仅在原生集合已初始化且计数0时写 None；实际计数、完整模板范围和SHA保留在原始记录。
- 参数、评分、坐标、计数和比例保留数值类型。Tm、GC、配对温差通常显示两位小数，ΔG一位小数，覆盖率用百分比。原生精度保留，不把显示舍入值当原始数值。

## 标黄、排序与人工选用

- 用户手工亮黄色 `#FFFF00` 表示其保留的候选；默认浅黄色 `#FFF2CC` 只是评价输入区，二者不能混淆。
- 版本迁移按序列ID、原候选编号和F/R序列核对标记、评价及备注，不按旧行号复制。拆行后已标黄的一对两行均保留亮黄，共用合并区也标黄；不要自行把“保留候选”改成“用户选用”。
- 主表按原始输入基因顺序排列，同基因保留已建立的候选/批次顺序。新增候选插入所属组内，例如 R07-4 紧接 R07-3，不放到第20条以后。结构明细和逐对截图按主表同样顺序排列。
- 用户明确指定某对时，记录“用户选用”并标黄；它可以超出自动首选+2备选的数量，仍须满足 False Priming 硬要求、保留真实结构警告、附图并完成该对特异性检查。不得因覆盖率或自动前三排序而漏掉用户指定的合格候选。

## 图片与改版保全

- 每对一张真实PP5完整结果子窗口截图，直接内嵌Excel；拆成F/R两行不等于需要两张图。图旁分别标明完整F/R新名称、原编号及5′→3′序列，图内仍保留软件真实界面。
- 核对截图配对身份、坐标、长度、Tm、False Priming、最稳定结构及ΔG；不得裁掉警告。OCR漏读单个位数坐标或负号时看原图确认并留记录，不能把OCR缺失解释成软件通过。
- 改版前后按原编号及F/R比较所有候选内容；逐张比较嵌入图片字节哈希、数量及其配对对应。保护其它工作表、结构原文、潜在产物、报告URL及输入来源。
- 如果当前文件在Excel中打开，保留用户尚未保存的内容；采用可用的安全编辑方式，或另存明确命名的修正版，不静默覆盖打开的旧文件。

## 公式验收：必须检查实际公式，不能只看缓存

在上述列布局中，每对F行记为 `a`，R行为 `b=a+1`：

| 计算单元格 | 正确公式 |
|---|---|
| I[a] 产物长度 | `=X[a]-W[a]+1` |
| S[a] 配对温差 | `=ABS(F[a]-F[b])` |
| AB[a] CDS重叠 | `=MAX(0,MIN(X[a],Z[a])-MAX(W[a],Y[a])+1)` |
| V[a] CDS覆盖率 | `=AB[a]/AA[a]` |

- 这套布局的主表，每对仅这4个计算公式；按实际配对位置生成精确的公式单元格集合。文字字段和合并下行不得有公式。其它工作表按其各自计算规则核查，不套用主表白名单。
- 已验证的导出缺陷：从旧版导入再 clear/重写，仍可能在XLSX中残留旧 `<f t="shared" ref="…" si="…">`。缓存值可正常显示，但Excel重新计算会覆盖文字并产生 `#VALUE!`。因此，成功 clear、工具内重算或“缓存无错误”都不能单独证明导出正确。
- 解包检查最终XLSX的真实 `<f>`：集合必须与预期一致；这套稀疏双行布局使用显式逐格公式，不保留跨合并下行的旧共享公式元数据。并核对所引用单元格的类型、地址和独立计算值。
- 导出器发生上述缺陷时，仅修复受影响工作表内已经确认的残留公式；按明确预期重建正确公式，保留数值和文本。避免删除其它工作表的合法公式，修复后比较其它ZIP部件及全部图片哈希。不要把历史批次的配对、公式或残留数量硬编码成通用规则。
- 在可用的Excel环境中打开最终文件，实际重算含公式工作表，扫描全部工作表的 `#VALUE!/#REF!/#DIV/0!/#NAME?/#N/A/#NUM!/#NULL!/#SPILL!/#CALC!`，再复查文字、评价、合并和图像。原生验收做不到时明确注明，不能声称已在Excel验证。
